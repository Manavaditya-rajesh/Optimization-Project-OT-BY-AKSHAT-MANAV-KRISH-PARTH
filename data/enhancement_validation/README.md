# Held-out synthetic data

These unchanged generator presets use reserved instance seeds 1010,1020,1030. The small regression uses only 1010; medium and large each use all three. Group sizes, room resources, faculty qualifications, availability and weekly demand are synthetic. Each problem has a separately saved feasible certificate in certificates/; solvers never receive it.

The matrix was declared before generating/inspecting held-out inputs. This remains a planted-feasible distribution with the original modeling assumptions; it is not real college data or an ITC benchmark.
